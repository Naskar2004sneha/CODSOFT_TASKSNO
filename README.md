Task 1: Data Cleaning and Preprocessing

Objective

To inspect and clean the Adult Census Income dataset using Python and Pandas.

Dataset

The Adult Census Income dataset is from the UCI Machine Learning Repository. It contains information about age, education, occupation, working hours, and income category.

Tools Used

Python

Pandas

Google Colab

Work Completed

Imported and inspected the dataset.

Added meaningful column names.

Identified missing entries represented by ?.

Removed rows containing missing entries.

Identified and removed duplicate records.

Checked numerical data types.

Removed unnecessary spaces from text columns.

Exported the cleaned dataset as a CSV file.

Results

Original dataset: 32,561 rows and 15 columns.

Rows removed for missing entries: 2,399.

Duplicate rows removed: 23.

Final dataset: 30,139 rows and 15 columns.

Missing entries remaining: 0.

Duplicate rows remaining: 0.

Project Files

CODSOFT_Task1_Data_Cleaning.ipynb — Python notebook containing the code.

cleaned_adult_data.csv — cleaned dataset.

Learning Outcomes

Practised data inspection, missing-value handling, duplicate removal, data-type checking, and CSV export using Python and Pandas.
