# CODSOFT Data Analytics Internship

This repository contains projects completed during the CODSOFT Data Analytics Internship.

## Task 1: Data Cleaning and Preprocessing
- Dataset: Adult Census Income Dataset
- Tools: Python, Pandas, Google Colab
- Work: Data inspection, missing-value handling, duplicate removal, data-type checking, and CSV export.
- Output: `cleaned_adult_data.csv`

## Task 2: Exploratory Data Analysis (EDA)
- Dataset: Cleaned Adult Census Income Dataset
- Tools: Python, Pandas, Matplotlib, Seaborn
- Work: Descriptive statistics, income distribution, education and income analysis, gender and income analysis, age-group analysis, working-hours analysis, workclass analysis, and correlation heatmap.
- Output: `Copy_of_CODSOFT_Task2_EDA.ipynb`
